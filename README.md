## Featured Projects

### [NorthStar Enterprise Analytics](https://github.com/Saner108/NorthStar-Enterprise-Analytics)

A retail inventory-visibility pilot using deterministic synthetic data, Python, SQLite, a star schema, validation queries, and an executive dashboard. It explores whether stockouts reflect inventory distribution issues or regional shortages. This is a scoped analytics pilot, not a production data feed; its findings describe simulated data, not real company performance.

[View dashboard](https://north-star-enterprise-analytics.vercel.app) · [Read findings](https://github.com/Saner108/NorthStar-Enterprise-Analytics/blob/main/06_Analysis/Phase5_Findings_Memo.md)

### [Excel Business Analytics Portfolio](https://github.com/Saner108/Excel-Business-Analytics-Portfolio)

Excel workbooks for financial calculations and capital budgeting, kitchen inventory tracking, and monthly/yearly personal budgeting. The repository contains multiple workbook versions; its README provides the current project navigation.

### [SLP Inventory Demo](https://github.com/Saner108/slp-inventory-demo)

Student coursework organizing equipment data into categories, shared model details, and individual item records in Excel and CSV for database preparation. Serial values are generated sample placeholders or an unverified source code. This is not verified company inventory or a finished Access application.

### [WaveWare Access Database Demo](https://github.com/Saner108/waveware-access-demo)

A near-final representative Microsoft Access application for exploring animal diet, inventory, weight, and reporting workflows. Selected employee names were replaced; other records remain, so the data is not fully anonymized or synthetic. It is not a current aquarium system or animal-care guidance, and native Access workflows were not re-tested after the sharing edit.

### [Python Projects](https://github.com/Saner108/Python-Projects/tree/Python_Based_Assignments)

Three standalone coursework scripts: a video rental calculator, a credit payment schedule, and a Lucky Sevens dice simulation. They practice user input/output, calculations, loops, and conditionals. The code lives on the `Python_Based_Assignments` default branch.

### [NutriCook AI](https://github.com/Saner108/nutricook-ai)

A React meal-planning application with Claude-powered recipe generation and optional Supabase and Stripe integrations. Unconfigured services have environment-specific sample/demo behavior; live recipe generation requires an API key. Nutrition values are AI estimates, not independently verified nutrition facts.
